# ADR-0006. 임베딩 2종은 로컬 CPU 실행 (SigLIP + bge-m3)

- 상태: 승인 (2026-07-11, 소급 기록)

## Context

임베딩을 로컬 실행하도록 권장한다(대량 인덱싱의 API 비용 회피). MVP 환경은 GPU 없는 Windows PC지만, 샘플 94쌍 규모면 CPU 추론으로 충분하다. 캡션은 한국어라 한국어 성능이 필요하다.

## Decision

이미지 임베딩 **SigLIP**, 텍스트 임베딩 **bge-m3**를 로컬 CPU로 실행한다. 시스템에서 지능(모델)이 있는 지점은 Claude API(오케스트레이터·T4)와 이 임베딩 2종뿐이며, 나머지는 결정적 코드다.

## Consequences

- (+) 인덱싱 API 비용 0, 오프라인 재실행 자유.
- (−) 최초 모델 다운로드 용량·CPU 추론 시간 — 94쌍 규모에서는 허용 범위.
