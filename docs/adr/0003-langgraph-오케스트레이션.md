# ADR-0003. 오케스트레이터를 LangGraph로 구현

- 상태: 승인 (2026-07-11, 소급 기록)

## Context

"LangGraph 또는 직접 구현 function calling"을 허용하되, 라우팅 로직이 코드에서 명시적으로 보일 것을 요구한다.

## Decision

ReAct 루프(6회 상한·병렬 도구 호출·중복 호출 가드·구조화 로그)를 **LangGraph** 그래프로 구현한다. 노드/엣지 구조로 라우팅을 명시하고, 상태(S0 Evidence Store)는 그래프 state로 관리한다.

## Consequences

- (+) 루프·분기·병렬이 그래프로 가시화되어 E3(라우팅 평가)·디버깅 용이. 기존 경험 재사용.
- (−) 프레임워크 의존 추가 — 에이전트 코어를 UI·평가 코드와 분리해 의존 전파를 막는다.
