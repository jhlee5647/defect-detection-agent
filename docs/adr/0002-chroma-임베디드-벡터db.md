# ADR-0002. 벡터 DB로 Chroma(임베디드) 채택

- 상태: 승인 (2026-07-11, 소급 기록)

## Context

벡터 DB 후보는 Qdrant와 Chroma다. MVP는 로컬 Windows PC 1대, 인덱스 규모는 이미지 ~94 + 텍스트 캡션 94건으로 작다. Docker 상시 구동은 개발 마찰만 늘린다.

## Decision

**Chroma 임베디드 모드**(별도 서버·Docker 불필요, 파일 기반 퍼시스턴스)로 V1(이미지)·V2(텍스트)를 구축한다.

## Consequences

- (+) 설치·실행 마찰 최소, pytest에서 임시 디렉토리로 쉽게 격리.
- (−) 대규모(10만 장) 전환 시 서버형(Qdrant 등) 재평가 필요 — 벡터스토어 접근을 인터페이스로 추상화해 교체 비용을 격리한다.
