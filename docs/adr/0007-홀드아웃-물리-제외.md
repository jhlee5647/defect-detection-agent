# ADR-0007. 홀드아웃은 V1·V2·D1 전부에서 물리 제외 (A-2 규칙)

- 상태: 승인 (2026-07-11, 소급 기록)

## Context

테스트셋 이미지의 벡터 DB 인덱스 제외를 실격 사유 수준으로 요구한다. 이미지 인덱스(V1)만 제외하면 캡션(V2)이나 이력 레코드(D1)를 통해 정답 정보가 우회 유입될 수 있다 — 홀드아웃 이미지의 캡션에는 정답 서술이, 이력 레코드에는 결함 종류·심각도가 그대로 들어 있다.

## Decision

풍력 결함 74장에서 클래스 층화로 뽑은 홀드아웃 ~20장은 **V1(이미지)·V2(캡션)·D1(이력) 세 저장소 모두에서 물리 제외**한다. 인덱싱 산출물에 홀드아웃 식별자가 존재하지 않는지 확인하는 차단 검사 스크립트를 두고 커밋 게이트에서 강제한다.

## Consequences

- (+) 검색·조회 어느 경로로도 정답 누수 불가. 평가 신뢰성 확보.
- (−) D1 이력이 실제보다 빈약해져 UC-5(이력 결합) 재현이 제약될 수 있음 — 홀드아웃 선정 시 고려하고, 필요하면 UC-5는 비홀드아웃 이미지로 시연.
