# ADR-0004. 평가(E1~E4)를 풍력 전용으로 한정

- 상태: 승인 (2026-07-11) — 기승인 개정안 B-3(태양광 E1/E2/E3 포함)을 대체

## Context

태양광은 640×512 열화상 단일 클래스(Hot Spot)로 풍력(8K RGB, 9클래스)과 분포가 완전히 다르다. 샘플의 태양광 결함은 3건뿐이고 QA도 2문항 변형이라 4문항 채점 체계와 맞지 않는다. 두 설비를 한 채점 체계에 섞으면 지표 해석이 흐려진다.

## Decision

**MVP·본진 모두 평가는 풍력 전용**으로 한다 (사용자 결정, 2026-07-11). 태양광은 인덱싱과 UC-6 기능 데모까지만 수행하고 E1~E3 채점에서 제외한다.

## Consequences

- (+) 채점 체계 단일화(4문항 VQA), 지표 해석 명확.
- (−) 태양광 성능은 정량 근거 없이 기능 시연만 — 리포트에 한계로 명시.
