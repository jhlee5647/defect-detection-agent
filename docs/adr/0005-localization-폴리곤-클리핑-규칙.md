# ADR-0005. 풍력 localization 정답 규칙 — 폴리곤∩크롭창 타이트 bbox

- 상태: 승인 (2026-07-11, 소급 기록)

## Context

풍력 VQA localization 보기는 1920×1080 크롭 좌표계다. annotations의 bbox(원본 좌표계)를 단순 평행이동하면 크롭 창을 벗어나는 결함에서 정답과 어긋난다. 샘플 실측 결과, 정답은 대표결함 **폴리곤을 크롭 창으로 클리핑한 뒤의 타이트 bbox**와 74/74 일치했다 (오차 ≤2px).

## Decision

VQA 채점기와 T4 크롭 로직의 localization 기준 좌표 계산을 "대표결함 폴리곤 → cropped_bbox 창으로 클리핑(Sutherland–Hodgman) → 타이트 bbox → 크롭 좌표계 변환"의 **공유 구현 하나**로 통일한다. 태양광은 크롭 없이 원본 좌표계 bbox(소수점 버림, 3/3 검증)를 쓴다.

## Consequences

- (+) 채점기·도구가 같은 좌표 변환을 사용해 평가-구현 불일치 제거.
- (−) 폴리곤 클리핑 구현·테스트 비용 — 전건 검증 스크립트로 회귀 방지.
